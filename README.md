### 프로젝트 소개
- 하모니, 소중한 사람들과의 추억 공유 서비스. '모니'와 대화를 하며 추억을 떠올리고, 가족/친구와 공유해요.

### 기능 소개
#### 🏠홈
<img src="https://github.com/user-attachments/assets/b00bf8f2-0be4-4941-9678-e13e2763e7dd" width=20% hegight=20%/>

- 새로운 추억 카드 확인 및 오늘의 일과의 개요를 볼 수 있는 화면
- 보호자가 보낸 추억 카드를 편지처럼 확인 
- 오늘의 일과를 리스트 형식으로 보기

- 하나의 질문 카드에 대한 상세 화면
